# Lockstep

複数の機器（macOS / Windows 11）で同じノベルゲームを動かし、親機の1操作を全機器へ同時に入れて、一手ずつ画面を見比べるための治具。

## 使い方

1. 全機器でゲームと Lockstep を起動する。
2. 1台を「親機」にする。画面に出るアドレス（例 `192.168.11.5`）を控える。
3. 残りを「子機」にし、親機のアドレスを入れて「接続」を押す。アドレスは次回も残る。切れても自動で繋ぎ直す。
4. 各機器で「操作するウィンドウ」からゲームを選ぶ。親機でも選べば、親機のゲームにも同じ操作が入る。
5. 親機のパッドをクリックするか、Lockstep が前面の状態でキーを押す。全機器に同じクリック／キーが入る。

- クリックは、パッド内の位置を各機器のゲームウィンドウ内の同じ割合の位置に変換して入れる。
- キーは「押して離す」1回として入る。長押しは伝わらない。対応キーは Enter・Space・Esc・Tab・Backspace・矢印・PageUp/Down・Home/End・英字・数字。
- ゲームが前面になければ自動で前面に出してから入れる。出せなければ入れずに失敗として表示する。
- 各機器に「適用済み n 手」が出る。親機には子機ごとの手数・遅れ・失敗理由が出る。数字が揃っていれば取りこぼしはない。

## 起動オプション

画面を操作せずに立ち上げるためのもの。引数でも環境変数（`LOCKSTEP_ROLE` など）でもよい。

| 引数 | 内容 |
|---|---|
| `--role=host` / `--role=client` | 役割を選んだ状態で起動する |
| `--host=192.168.11.5` | 子機: このアドレスへ接続する |
| `--target=名前` | アプリ名にこの文字列を含む最初のウィンドウを選ぶ |
| `--autosend=ArrowDown,click` | 親機・デバッグビルドのみ: 起動6秒後から2秒おきに順に送る |

## ビルド

```
npm install
npm run tauri build                                        # その機器向け
npm run tauri build -- --target universal-apple-darwin     # Intel / Apple Silicon 両対応の dmg
```

フロントは `ui/` の静的ファイルで、ビルド工程はない。Windows 版は Windows 上でビルドする。

## 知っておくこと

- **通信**: 親機が TCP 47831 番で待ち受ける。OSやセキュリティソフトが着信を止める場合は Lockstep を許可する。
- **macOS の権限**: 「アクセシビリティ」の許可が要る。署名のないビルドは作り直すたびに許可が外れることがある。
- **macOS の入力経路**: 合成入力はセッション層へ送る。Deskflow などキーボード共有ソフトが HID 層の入力を止めていても届く。
- **macOS の前面化はアプリ単位**。同じアプリの複数ウィンドウは撃ち分けられない。
- **クリック位置の基準が OS で違う**: macOS はタイトルバーを含むウィンドウ全体、Windows はクライアント領域。ウィンドウ表示の macOS では縦にタイトルバー分ずれるので、位置が重要なときはフルスクリーンで動かす。
- 役割を変えるときはアプリを起動し直す。
